# ptoart 小白使用教程

照片 → 卡通头像 / 整张照片卡通化 / 宫崎骏等动漫风格。全部在你自己的电脑或手机上离线处理，照片不上传。

下载页：**https://github.com/sincalaway/ptoart/releases/latest**（往下拉到 **Assets**，点文件名即可下载）。**所有模型都已内置在 App 里**：安卓只下载 APK，Windows 只下载一个 zip，不用再下载任何模型。

---

## 一、安卓手机（最简单）

**只要下载一个文件**（用手机浏览器打开上面的下载页）：`ptoart-android.apk`（约 270 MB，所有模型都已在里面）。

**步骤：**

1. 点开下载好的 `ptoart-android.apk` 安装。手机提示“禁止安装未知来源应用”时，按提示允许浏览器/文件管理器安装即可（安卓 7.0 及以上）。
2. 打开 App，**不用导入任何模型**，下拉框里已经列出所有模式和画风。
3. 在下拉框选模式：
   - **卡通头像**：最大那张脸，输出 512×512 头像；
   - **整张照片**：照片里每张脸都卡通化，再贴回原图，身体和背景不变；
   - **整图风格：宫崎骏 / 新海诚…**：整张图变动漫风，风景、全身照都能用。

   模式下拉框里写着「卡通头像 · 动漫脸（推荐）」这类名字，前半是模式、后半是画风。给**宝宝、小朋友**的照片优先试「DCT 3D」或「DCT 日漫」。
4. 点 **「选择照片」→「开始转换」**，满意后点 **「保存 PNG」** 选个位置保存。
5. 想更清晰就打开 **「超分辨率增强」** 开关（会慢几秒），下面可以选「动漫（快）」或「通用（照片）」。
6. 「导入模型」按钮可以不管：只有想换成自己的 .onnx 模型时才用。

---

## 二、Windows 电脑

解压后**双击 `ptoart.exe` 就会打开图形界面**，不用敲命令，也不用另外下载模型。

**只要下载一个文件**（电脑浏览器打开下载页）：`ptoart-windows-x64.zip`（约 1 GB，所有模型都已在里面）。

**步骤：**

1. 右键 `ptoart-windows-x64.zip` → **全部解压缩**，比如解压到 `C:\ptoart`。不要在压缩包里直接运行。
2. 模型已经全部在 `weights` 文件夹里，不用动它（不要移动、改名或删除）：

   ```text
   ptoart\
   ├── ptoart.exe            ← 双击打开图形界面
   ├── 1-avatar.bat          ← 拖照片到这里：卡通头像
   ├── 2-whole-photo.bat     ← 拖照片到这里：整张照片卡通化
   ├── 3-style-hayao.bat     ← 拖照片到这里：宫崎骏风格
   ├── _internal\
   └── weights\              ← 所有模型，已内置
       ├── ptoart_weights.pt、seg_model_384.pb
       ├── styles\hayao.onnx、jp_face.onnx、dct_3d.onnx …（风格 11 个 + DCT 5 个）
       ├── upscale\anime.onnx、general.onnx
       └── torch\（人脸检测模型）
   ```

3. **双击 `ptoart.exe`**，在窗口里：
   1. 点 **「＋ 选择照片」**（可多选）；
   2. 选效果：**卡通头像 / 整张照片 / 整图风格**，整图风格再选宫崎骏、新海诚等；
   3. 在「头像画风」列表里点一下即选中（选中的那一项变成蓝底、前面有 ✓，窗口顶部也会写「✓ 头像画风：…」，并短暂提示「已选择…」）：**动漫脸（推荐）**、**DCT 日漫**、**DCT 3D**、**DCT 手绘**、**日漫二次元**、**吉卜力人像**、**黑白素描**、**经典卡通**。给**宝宝、小朋友**的照片优先试 **DCT 3D**（最像本人）或 **DCT 日漫**（最可爱）；DCT 画风在整张照片模式下会把背景一起变成卡通；头像可选尺寸 512/1024/2048、卡通强度、透明背景；**「超分辨率增强」** 默认打开，可选动漫或通用；
   4. 点「开始转换 →」。每次的结果都会**自动保存**到照片旁的 `ptoart输出` 文件夹（窗口底部显示完整路径）。窗口**顶部工具栏**：**「↶ 撤销」(Ctrl+Z)**、**「↷ 重做」(Ctrl+Y)** 在几次结果间切换（没得撤销/重做时是灰色的）；**「保存」(Ctrl+S)** 确认当前这张已经存好并显示存在哪里；**「另存为…」** 存到别处；**「打开输出文件夹」** 直接打开。效果图上方写明用的是哪个模式、画风和强度；出图后又换了画风或设置，会出现黄色提示「设置已更改」，点 **「用新设置重新生成」** 即可。
   - 窗口左下角显示模型状态，正常应该全部是 ✓。
   - 也可以不开窗口：把照片直接拖到 `1-avatar.bat` 等文件上，结果在 `output` 文件夹。
4. 所有模型（包括 `weights\torch` 里的人脸检测模型）都已打包，**无需联网**；启动时后台加载一次，之后不再重复加载。
5. Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**（程序未做数字签名）。

所有功能（风格、尺寸、强度、透明背景、超分、批量）都在窗口里点选，不需要命令行。

## 三、常见问题

- **提示找不到模型**：模型都内置在 `weights` 文件夹里。请确认是从下载页的 `ptoart-windows-x64.zip` 完整解压出来的，`weights` 没被移动、改名或删除；重新解压一次即可。安卓 APK 也已内置全部模型，不需要导入。
- **没检测到人脸**：用正脸、清晰、光线好的照片；侧脸、遮挡、太小的脸可能检测不到。只想要动漫风可以用“整图风格”，它不需要人脸。
- **太慢**：纯 CPU 运行，大图 + 超分可能要十几秒到一分钟，属正常。
- **能商用吗**：卡通头像（MIT）、DCT 画风（阿里达摩院 DCT-Net，Apache-2.0）和超分（Real-ESRGAN，BSD-3）可以；**AnimeGANv2/v3 风格和画风仅限非商业用途**。
