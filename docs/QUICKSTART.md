# ptoart 小白使用教程

照片 → 卡通头像 / 整张照片卡通化 / 宫崎骏等动漫风格。全部在你自己的电脑或手机上离线处理，照片不上传。

所有文件都在同一个下载页：**https://github.com/sincalaway/ptoart/releases/latest**（往下拉到 **Assets**，点文件名即可下载）。

---

## 一、安卓手机（最简单）

**要下载的文件**（用手机浏览器打开上面的下载页）：

| 文件 | 必需？ | 作用 |
| --- | --- | --- |
| `ptoart-android.apk` | 必需 | App 安装包 |
| `ptoart_weights.onnx` | 必需（做卡通头像） | 卡通头像模型 |
| `ptoart-styles.zip` | 可选 | 11 种风格，含动漫脸、日漫二次元、吉卜力人像、黑白素描 4 种头像画风（强烈推荐） |
| `ptoart-upscalers-realesrgan.zip` | 可选 | 让结果更清晰的超分模型 |

**步骤：**

1. 点开下载好的 `ptoart-android.apk` 安装。手机提示“禁止安装未知来源应用”时，按提示允许浏览器/文件管理器安装即可（安卓 7.0 及以上）。
2. 两个 zip 先用手机自带的“文件管理”解压（长按 → 解压）。
3. 打开 App，点 **「导入模型（.onnx，可多选）」**，选中 `ptoart_weights.onnx`；强烈建议把风格包 `ptoart-styles.zip` 解压后的 .onnx 全部多选导入：会多出「动漫脸（推荐）」「日漫二次元」「吉卜力人像」「黑白素描」头像画风，以及宫崎骏、新海诚等 11 种整图风格；想要高清再导入 `anime.onnx`。导入一次即可，以后不用再导。
4. 在下拉框选模式：
   - **卡通头像**：最大那张脸，输出 512×512 头像；
   - **整张照片**：照片里每张脸都卡通化，再贴回原图，身体和背景不变；
   - **整图风格：宫崎骏 / 新海诚…**：整张图变动漫风，风景、全身照都能用。
5. 点 **「选择照片」→「开始转换」**，满意后点 **「保存 PNG」** 选个位置保存。模式下拉框里写着「卡通头像 · 动漫脸（推荐）」这类名字，前半是模式、后半是画风，选哪个就用哪个。
6. 想更清晰就打开 **「超分辨率增强」** 开关（会慢几秒）。

## 二、Windows 电脑

解压、放好模型后，**双击 `ptoart.exe` 就会打开图形界面**，不用敲命令。

**要下载的文件**（电脑浏览器打开下载页）：

| 文件 | 必需？ |
| --- | --- |
| `ptoart-windows-x64.zip` | 必需 |
| `ptoart_weights.pt` | 必需（头像、整张照片） |
| `seg_model_384.pb` | 必需（头像、整张照片） |
| `ptoart-styles.zip` | 强烈推荐（11 种风格，含 4 种头像画风） |
| `ptoart-upscalers-realesrgan.zip` | 可选（更清晰） |

**步骤：**

1. 右键 `ptoart-windows-x64.zip` → **全部解压缩**，比如解压到 `C:\ptoart`。不要在压缩包里直接运行。
2. 把 `ptoart_weights.pt` 和 `seg_model_384.pb` 放进 `C:\ptoart\ptoart\weights` 文件夹。
3. （可选）把风格 zip 解压到 `weights\styles`，把超分 zip 解压到 `weights\upscale`。最终像这样：

   ```text
   ptoart\
   ├── ptoart.exe            ← 双击打开图形界面
   ├── 1-avatar.bat          ← 拖照片到这里：卡通头像
   ├── 2-whole-photo.bat     ← 拖照片到这里：整张照片卡通化
   ├── 3-style-hayao.bat     ← 拖照片到这里：宫崎骏风格
   ├── _internal\
   └── weights\
       ├── ptoart_weights.pt
       ├── seg_model_384.pb
       ├── styles\hayao.onnx、jp_face.onnx …（11 个）
       └── torch\（人脸检测模型，已附带，勿删）
       └── upscale\anime.onnx、general.onnx
   ```

4. **双击 `ptoart.exe`**，在窗口里：
   1. 点 **「＋ 选择照片」**（可多选）；
   2. 选效果：**卡通头像 / 整张照片 / 整图风格**，整图风格再选宫崎骏、新海诚等；
   3. 「画风」可选 **动漫脸（推荐）**、**日漫二次元**、**吉卜力人像**、**黑白素描**、**经典卡通**：前四种五官自然不变形，小朋友、长辈的照片都好看（来自风格包 `ptoart-styles.zip`）；头像可选尺寸 512/1024/2048、卡通强度、透明背景；放了超分模型会自动打开 **「超分辨率增强」**；
   4. 点「开始转换 →」。每次的结果都会**自动保存**到照片旁的 `ptoart输出` 文件夹（窗口底部显示完整路径，点「打开输出文件夹」直接打开）；「↶ 撤销 / ↷ 重做」在几次结果间切换，「另存为…」存到别处。效果图上方会写明用的是哪个模式、画风和强度；改了设置后按钮会变成「应用新设置」。
   - 窗口左下角会显示哪些模型已就绪（✓）；缺模型时点「打开模型文件夹」把文件放进去，再点「重新检测模型」。
   - 也可以不开窗口：把照片直接拖到 `1-avatar.bat` 等文件上，结果在 `output` 文件夹。
5. 人脸检测模型已打包在 `weights\torch` 里，**无需联网**；启动时后台加载一次，之后不再重复加载。
6. Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**（程序未做数字签名）。

所有功能（风格、尺寸、强度、透明背景、超分、批量）都在窗口里点选，不需要命令行。

## 三、常见问题

- **提示找不到模型**：检查文件名没被改（如变成 `ptoart_weights (1).pt`），且放在 `weights` 文件夹里。
- **没检测到人脸**：用正脸、清晰、光线好的照片；侧脸、遮挡、太小的脸可能检测不到。只想要动漫风可以用“整图风格”，它不需要人脸。
- **太慢**：纯 CPU 运行，大图 + 超分可能要十几秒到一分钟，属正常。
- **能商用吗**：卡通头像（MIT）和超分（Real-ESRGAN，BSD-3）可以；**AnimeGANv2 整图风格仅限非商业用途**。
